# Security policy

## Reporting a vulnerability

**Do not open a public issue.** Report suspected vulnerabilities privately:

- Use GitHub's **"Report a vulnerability"** (Security → Advisories) on this repository, or
- email **security@axelliant.com** with a description, reproduction steps and the affected version.

We acknowledge within two working days and keep you informed until the issue is resolved. Please give
us reasonable time to fix before any disclosure.

## If you find a secret

A credential, token or key in this repository or its history is an incident. Report it as above
immediately; do not use it, and do not paste it anywhere. It will be rotated — removing it from the
file does not un-publish it.
